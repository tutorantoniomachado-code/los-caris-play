# ❤️ Los Caris Play

**Versión:** Alpha 0.1

Juego para parejas desarrollado como una aplicación web moderna (PWA), optimizada para teléfonos móviles y preparada para instalarse como una aplicación.

---

# Objetivo

Los Caris Play es un juego pensado para dinamizar momentos en pareja mediante retos aleatorios compuestos por una acción y una condición.

Ejemplo:

❤️ Acción

> Dar un beso

🔥 Condición

> Con los ojos cerrados

Cada reto debe realizarse antes de que finalice el tiempo.

# Cómo ejecutar el proyecto

1. Abrir la carpeta **LosCarisPlay** con Visual Studio Code.

2. Instalar la extensión **Live Server**.

3. Abrir el archivo

```
index.html
```

4. Pulsar

```
Open With Live Server
```

La aplicación se abrirá automáticamente en el navegador.
